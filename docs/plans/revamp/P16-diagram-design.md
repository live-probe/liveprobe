# P16 다이어그램 개선

## 요청과 범위 확정

사용자 요청: AI 분석 흐름과 시스템 관제 다이어그램의 디자인을 개선한다. 기존 권장안 위임과 Jira 연결 금지를 유지한다. 과제계획서 전체, P15 화면 계약, 현행 코드, 실제 지도와 장애 #1019를 확인했다. 새 기능이나 실행 권한의 결정은 없으므로 추가 인터뷰 없이 시각 개선으로 한정한다.

## 현재 화면의 문제

- 지도: 동일한 흰 카드와 의미 없는 문자 아이콘, 반복되는 작은 미관측 지표, 묶음·연결·장애의 약한 위계.
- AI 흐름: 모든 완료 노드가 같은 녹색 테두리이며 종류·단계·모델·상태가 분리되지 않는다. 작은 두 줄 사각형들이 단순 연결돼 역할 차이가 읽히지 않는다.
- 기존 동작은 보존해야 한다. 장애 위치 진입, 미관측 구분, 전체 상세 수치, depth/lane, 승격·병렬 경로, 키보드 선택·근거 연결, 승인·대화 영역이 대상이다.

## 작업 항목

1. D16-1: 다이어그램 전용 흑연색 토큰·역할 아이콘·명도 위계. 기준: dashboard/DESIGN.md P16 절.
2. D16-2: 서비스 지도 노드·네임스페이스·요약·연결선·범례 정교화. 원천 수치와 장애 진입 유지.
3. D16-3: AI 단계 종류·순번·상태·모델 위계와 연결선 정교화. 세로·병렬·선택 동작 유지.
4. D16-4: 기존 단위·모의 브라우저 회귀, 새 디자인 상태·명도 대비·1440/768/375 캡처 및 직접 검토.
5. D16-5: 기존 dashboard Deployment만 백업 후 교체, 제공 정적 파일과 로컬 빌드 해시 일치·실배포 읽기 전용 검증.

## 제외

백엔드·인증·실제 장애 주입·승인·Secret 변경·클러스터 구성 변경·평가 제품 화면·외부 게시·커밋·push. 기존 API 배포는 바꾸지 않는다. 실배포 검증은 읽기 전용이다.

## 완료 기준

두 실제 화면에 변경이 배포되고, 자동 회귀가 통과하며, 세 가지 폭의 캡처를 직접 확인한다. 결함이 있으면 수정 뒤 재캡처한다. 시험 건너뜀·실험실 성능·재사용 런타임 빌드의 한계를 구분해 기록한다.
